# Piloto com a barbearia parceira

**Data:** 2026-08-03 · **Objeto:** transformar a primeira barbearia em prova de venda, sem transformar o produto em consultoria.

O parceiro é o ativo mais importante e mais frágil do plano. Ele é, ao mesmo tempo: primeiro usuário, fonte de todo número que vai ao ar, rosto do caso, e o primeiro sujeito capaz de pedir uma exceção que quebra o produto. Este documento trata dos quatro papéis.

---

## 1. O acordo — combine antes, por escrito

Não precisa ser contrato de advogado. Precisa estar escrito e aceito no WhatsApp, porque **acordo verbal com amigo é onde a relação azeda**.

### 1.1 O que ele recebe

| | |
|---|---|
| **Sistema** | Gratuito e vitalício, enquanto ele quiser usar. Não é desconto de 12 meses — é vitalício, e vale dizer isso com todas as letras |
| **Onboarding** | Você configura tudo: serviços, preços, horários, política, despesas. Ele não mexe em nada na largada |
| **Suporte** | Direto com você, sem fila |
| **Diagnóstico** | O raio-X financeiro do negócio dele, todo mês, mesmo que ele parasse de usar o sistema amanhã |
| **Exposição** | A barbearia dele aparece nos vídeos, com nome. Para uma barbearia local, isso é mídia |

### 1.2 O que você recebe

| | |
|---|---|
| **Dado real** | Autorização para usar os números agregados dele nos vídeos |
| **Imagem** | Autorização para gravar dentro da barbearia e para ele aparecer |
| **Feedback** | Uma conversa de 20 minutos por semana, no primeiro mês |
| **Referência** | Ele atende ligação de barbeiro interessado — é a prova social que mais converte no nicho |

### 1.3 O que fica combinado que NÃO acontece

Esta é a parte que ninguém combina e que depois cobra caro:

1. **Ele não decide o roadmap.** O feedback dele tem peso enorme; a decisão é sua. A [`ESTRATEGIA-SAAS §8`](../ESTRATEGIA-SAAS.md) nomeia isso como o modo mais provável do projeto dar errado: a primeira barbearia pede algo estrutural, você diz sim, e o produto vira consultoria com login.
2. **Nada exclusivo.** Nenhuma função existe só para ele. Se a ideia é boa, entra para todo mundo; se serve só para ele, não entra.
3. **Nenhum número sai sem o aval dele.** Cada valor que vai à tela é mostrado antes.
4. **Ele pode sair quando quiser** e leva os dados dele. Diga isso na largada — remove o medo de aprisionamento, que é a objeção silenciosa de todo dono.

### 1.4 A mensagem de acordo (modelo)

> Fechando o que a gente combinou, pra ficar registrado:
>
> **Você recebe:** o sistema de graça pra sempre, eu configurando tudo, suporte direto comigo, e o raio-X financeiro da barbearia todo mês.
>
> **Eu recebo:** poder usar os números da barbearia nos vídeos (sempre te mostrando antes de publicar), poder gravar aí dentro, 20 minutos por semana de conversa no primeiro mês, e você atendendo o barbeiro que ligar querendo saber se funciona.
>
> **Duas coisas importantes:** o que eu construir vale pra todas as barbearias, não dá pra fazer função exclusiva sua. E os dados são seus — se um dia você quiser parar, eu te entrego tudo e não tem multa nem nada.
>
> Beleza assim?

## 2. Autorização de uso de imagem e dados

Guarde o aceite dele. Uma mensagem de WhatsApp com o texto abaixo e um "ok" resolve nesta fase.

> Eu, ⟨nome⟩, dono da ⟨Barbearia⟩, autorizo ⟨seu nome⟩ a:
>
> 1. Gravar imagens dentro da barbearia e usar em vídeos de divulgação;
> 2. Usar minha imagem e minha voz nesses vídeos;
> 3. Divulgar números agregados do meu negócio (faturamento, atendimentos, ticket médio, faltas, resultado), **sem qualquer dado de cliente**;
> 4. Citar o nome da barbearia como caso de uso.
>
> Fica combinado que nenhum número é publicado sem eu ver antes, e que posso pedir a retirada de qualquer vídeo a qualquer momento.

**A cláusula de retirada não é formalidade.** É o que faz ele aceitar a de divulgação sem hesitar.

### 2.1 Dado de cliente final — a linha que não se cruza

O que ele autoriza é **dado agregado do negócio dele**. Nome, telefone e histórico dos clientes finais **não são dele para autorizar** — são dos clientes.

Por isso a regra da [pesquisa §6.2](./PESQUISA-MERCADO-CONTEUDO.md#62-lgpd--o-erro-que-a-pressa-produz) vale sem exceção: **toda gravação de tela é feita em tenant de demonstração, com nomes fictícios.** Vale inclusive — e principalmente — quando o take em produção "ficou melhor".

## 3. Coleta de prova — comece no dia 1, não no dia 30

O erro clássico: usar o sistema por dois meses e só então perceber que não existe registro do "antes". **Sem o antes, não existe caso.**

### 3.1 A foto do antes — capture na primeira conversa

Antes de configurar qualquer coisa, sente com ele e registre (áudio ou anotação):

| Pergunta | Vira |
|---|---|
| "Como você sabe hoje se o mês foi bom?" | A fala de abertura do E1 |
| "Quanto entrou mês passado?" | Linha de base de receita |
| "Quanto você acha que sobrou?" | **O número mais valioso do piloto** — é o palpite dele, que depois vai bater de frente com o real |
| "Quanto você paga de fixo por mês?" | Base do custo fixo |
| "Quantos atendimentos por dia?" | Volume |
| "Quantos furaram no mês passado?" | Base de no-show (a estimativa dele) |
| "Quanto tempo você gasta por dia com agenda e WhatsApp?" | Ganho de tempo |
| "Qual foi a última decisão que você tomou no negócio? Como decidiu?" | Prova de decisão sem dado |

**Grave o áudio dessa conversa.** Com autorização. É matéria-prima de vídeo do ano inteiro — e a frase que vira o manifesto (D1) quase sempre sai daqui.

### 3.2 O placar do piloto

Planilha simples, atualizada semanalmente:

| Indicador | Antes (estimado por ele) | Semana 4 | Semana 8 | Semana 12 |
|---|---|---|---|---|
| Faturamento do mês | | | | |
| Atendimentos | | | | |
| Ticket médio | | | | |
| Faltas (nº e R$) | | | | |
| Custo fixo mensal | | | | |
| **Resultado do mês** | *não sabia* | | | |
| **Ponto de equilíbrio** | *não sabia* | | | |
| Ocupação % | *não sabia* | | | |
| Tempo/dia com agenda | | | | |
| Clientes marcados como "sumiu" | | | | |

**As três linhas "não sabia" são o caso inteiro.** O ganho mais vendável do piloto não é faturar mais — é passar de "não sabia" para um número. Fale disso, não de crescimento de receita, que depende de mil variáveis fora do sistema.

### 3.3 O que dá para prometer e o que não dá

| ✅ Pode virar afirmação | ❌ Não pode |
|---|---|
| "Ele não sabia o resultado do mês. Agora sabe." | "Aumentou o faturamento em X%" — não dá pra atribuir ao sistema |
| "Ele descobriu que perdeu ⟨R$ 518⟩ em faltas." | "Reduziu no-show em 70%" — o produto ainda não manda lembrete |
| "Ele fecha o caixa em ⟨20⟩ segundos, sem somar nada." | "Economiza 10 horas por semana" — sem medição, é chute |
| "Ele descobriu que a terça das 14h tem ⟨18%⟩ de ocupação." | Qualquer projeção de ganho futuro |

**A régua:** se o número não estiver no placar da §3.2, ele não vai à tela.

## 4. As 12 semanas

### Semana 0 — antes de qualquer configuração
- [ ] Conversa do "antes" gravada (§3.1)
- [ ] Acordo aceito por escrito (§1.4) e autorização registrada (§2)
- [ ] Placar criado com a coluna "antes" preenchida

### Semanas 1–2 — instalação e uso real
- [ ] Tenant provisionado, serviços, preços, horários e políticas configurados **por você**
- [ ] Despesas fixas do mês lançadas — sem elas, o DRE não existe
- [ ] PWA instalado no celular dele, com ícone da barbearia
- [ ] Link de agendamento na bio do Instagram da barbearia
- [ ] Conversa de 20 min ao fim de cada semana
- [ ] **Anotar toda fricção**, principalmente as que ele não reclama — o que ele deixa de usar diz mais que o que ele elogia

### Semanas 3–4 — o primeiro mês fecha
- [ ] **Gravar o E3** — a reação dele vendo o primeiro DRE. Irrepetível: prepare a câmera antes ([`ROTEIROS E3`](./ROTEIROS-VIDEOS.md#e3--a-primeira-vez-que-ele-vê-o-dre-dele--o-ativo-mais-valioso))
- [ ] Comparar o palpite dele (§3.1) com o resultado real → **este contraste é o melhor conteúdo do piloto**
- [ ] Preencher a coluna "semana 4"
- [ ] Gravar o E1 (as 7 perguntas)

### Semanas 5–8 — o caso vira material
- [ ] E2 (antes/depois em números) com dado real dos dois meses
- [ ] Ele atende a primeira ligação de barbeiro interessado
- [ ] Pedir a ele **três indicações** de donos que ele respeita — indicação de par converte muito acima de qualquer vídeo
- [ ] Coluna "semana 8"

### Semanas 9–12 — validação de preço
- [ ] **A pergunta que a documentação de preço diz que falta** ([`PLANOS §4`](../PLANOS-E-FUNCIONALIDADES.md)): *"Se não fosse de graça, quanto você pagaria por isso?"* — pergunte depois de ele já depender do sistema, não antes
- [ ] *"Quanto você acha que perdia por mês antes disso?"*
- [ ] Coluna "semana 12" e fechamento do caso
- [ ] Caso completo vira o vídeo fixado do perfil do produto

## 5. Riscos do piloto

| Risco | Sinal de alerta | O que fazer |
|---|---|---|
| **Ele pede exceção estrutural** | "Só precisava que o DRE tivesse mais uma linha pra mim" | Diga não explicando o porquê. Ofereça a alternativa dentro do que é parametrizável ([`ESTRATEGIA-SAAS §4`](../ESTRATEGIA-SAAS.md)). Um sim aqui contamina o produto inteiro |
| **Ele para de usar e não avisa** | Sem atendimento concluído por 3 dias | Vá até lá. Por WhatsApp ele diz que está tudo bem; na barbearia você vê o caderno aberto na bancada |
| **Amizade impede o feedback honesto** | Só elogio, nenhuma crítica | Pergunte pelo negativo diretamente: "o que te irritou essa semana?". E **mantenha a crítica dele no corte final do E1** |
| **Um piloto só não prova** | Objeção "funcionou pra ele, a minha é diferente" | Trazer a 2ª e a 3ª barbearia rápido, ainda no preço de fundador. Um caso é anedota; três é padrão |
| **Dado ruim envergonha ele** | Resultado do mês negativo | Pergunte se pode publicar. **Se ele topar, é o melhor conteúdo possível.** Se não, respeite na hora e não insista |
| **Ele vira sócio na cabeça dele** | "a gente devia cobrar X", "nosso sistema" | Trate cedo e com carinho. Se a intenção for sociedade de verdade, é conversa separada, escrita, com números — não um mal-entendido que cresce |

## 6. Depois do piloto — as próximas 19

O [preço de fundador](../PLANOS-E-FUNCIONALIDADES.md) prevê 20 barbearias a 50% por 12 meses. A parceira é a número zero — vitalícia e fora da conta.

**Ordem de prospecção, da maior para a menor taxa de conversão:**

1. **Indicações do parceiro** — dono que confia em dono é o canal mais forte do nicho
2. **Quem fez raio-X e não fechou** — já entregou os números, já viu valor. Volte em 30 dias com o número atualizado
3. **Comentários e DMs do conteúdo**
4. **Barbearias do bairro, presencialmente** — leve o raio-X pronto no celular, não um folheto

**Não escale conteúdo antes de fechar a 3ª barbearia paga.** Se três não fecham com o funil funcionando, o problema não está no alcance — está no produto, no preço ou na oferta. Mais vídeo só amplifica o problema errado.
